# Глоссарий локализации ruRU

Этот глоссарий фиксирует согласованные названия и формулировки для локализации модуля. Штатные названия клиента WoW 3.3.5a сохраняются там, где это указано.

| English / понятие | Русская форма | Примечание |
| --- | --- | --- |
| Ability Essence / Talent Essence | эссенция способностей / эссенция талантов | Сокращения валют: ЭС / ЭТ. |
| ability roll / ability reroll | бросок способности / переброс способности | «Бросок» — получение способности; «переброс» — замена уже полученной. Не смешивать эти действия. |
| Bloodsworn | связанный кровной клятвой | Противник, не нарушитель клятвы. |
| Chaos Bolt (Spell 50796) | Стрела Хаоса | Штатное название ruRU клиента. |
| critical strike chance / spell critical strike chance | вероятность критического удара / вероятность критического эффекта заклинаний | Использовать точную форму по контексту. |
| Frost (TalentTab 61/399) | Лед | Написание как в ruRU `TalentTab.dbc`. |
| heirloom ability / heirloom gear | фамильная способность / фамильное снаряжение | Авторский термин проекта. |
| mana regeneration | восполнение маны | Единая форма в технических описаниях. |
| stealth state | состояние незаметности | Требование находиться незаметным; «Скрытность» — название ветки талантов. |
| Nemesis run | испытание «Немезида» | В названиях трофеев и описаниях. |
| Nemesis traits | Жажда крови; Железная шкура; Защита от чар; Ядовитость; Несгибаемость | Единые названия характеристик; эпитет существа может склоняться. |
| Rend (Spell 772) | Кровопускание | Штатное название ruRU клиента. |
| Respec action | Сброс сборки | Одна подпись действия в интерфейсе. |
| stars in trophy descriptions | Звёзд: N | Нейтральная форма для любого числа звёзд. |
| Sworn / Marked | Связанная клятвой / Помеченная | Не использовать «Призванная» для Sworn Nemesis. |
| Vengeance counter | Мщение | Название счётчика; «Клятва мести» остаётся названием заклинания. |
| damage schools | урон от темной магии / магии Света / магии льда / сил природы / тайной магии / огня | Единый стиль технических описаний: использовать «урон от огня», «урон от магии льда», «урон от темной магии», «урон от магии Света» и «урон от тайной магии». Сохранять прописную букву в названии школы «Свет». |
