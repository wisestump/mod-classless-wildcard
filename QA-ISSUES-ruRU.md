# Новые баги ruRU

Файл содержит только новые проблемы игрового интерфейса, замеченные пользователем. Служебные инструменты установки и разработки сюда не включать. Перед добавлением сверять находку с уже записанными пунктами; старые закрытые или снятые пользователем наблюдения удалять по его просьбе.

## Как фиксировать баги по скриншотам

- Разбирать весь видимый интерфейс: английские и смешанные строки, обрезанный текст, надписи, не помещающиеся на кнопках, наложения и неудачные сокращения.
- Для каждого самостоятельного дефекта указывать экран и место, видимый текст/проблему, конкретное ожидаемое изменение и источник — скриншот из переписки.
- Если пользователь предложил точную формулировку или сокращение, записывать её как ожидаемый вариант. Если формулировка не задана, описывать нужный результат, не придумывая перевод без необходимости.
- Не дублировать одну проблему из нескольких скриншотов: объединять примеры и перечислять отличающиеся состояния в одном пункте.
- Не додумывать невидимые причины и случаи. Отмечать только то, что подтверждает скриншот; неясности явно помечать.
- Добавление бага само по себе не означает разрешение исправлять код: сначала вести список здесь и начинать реализацию только по просьбе пользователя.
- Писать кратко, но так, чтобы дефект можно было воспроизвести и проверить после исправления.

### Шаблон записи

#### Краткое название дефекта

- **Приоритет:** P1 / P2 / P3
- **Где:** экран и конкретная область интерфейса.
- **Проблема:** что именно видно на скриншоте.
- **Ожидаемое изменение:** конкретный результат или согласованная формулировка.
- **Источник:** скриншот из переписки.
